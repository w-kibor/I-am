# Favicon Folder

Place your favicon image files in this folder.

### Recommended formats & filenames:
- **`favicon.ico`** (Standard favicon icon for browsers)
- **`favicon.png`** (PNG high-resolution icon)
- **`favicon.svg`** (Vector format icon)
- **`apple-touch-icon.png`** (180x180 for iOS home screen shortcuts)

`index.html` has been configured to load your favicon automatically from `/favicon/favicon.ico` (or `.png` / `.svg`).
